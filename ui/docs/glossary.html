Glossary

Every word the Mailroom uses, in plain language, with a link to where it is explained in full.

The Mailroom is an office mailroom. A parcel is a request. A key says who is sending. A contract says what that sender may do. The desk is the Hub in the cloud. The laptop is where the work is done.

The words

A C D E H K L M O P Q R S T W

A
Admin token
A secret that starts with mra_. It lets Claude or another MCP app look at, and maybe manage, your Mailroom. Only you can make one. Claude and other apps
Append-only
A log you can only add to. Old lines are never edited or removed. The event log works this way. Events
Approval
The yes you give before a risky parcel runs. The contract lists which tasks wait for one. Parcels and approvals
Approve (scope)
The admin-token scope that can approve or decline waiting parcels. It is the dangerous one, because it releases a risky step. Claude and other apps
Audit trail
The record of what an admin token did. Each write or approve call adds an mcp.call event. Claude and other apps
C
Client
An app or program that sends parcels to the Mailroom with a client key. The big picture
Client key
The secret an app uses to send parcels. It starts with mr_live_ and is tied to one contract. Keys and contracts
Contract
The list of what one key may do: which folders, which tasks, how many parcels a day, when it expires and which tasks wait for you. Keys and contracts
Credential
Any secret that proves who you are. The Mailroom has four kinds: client key, daemon credential, owner session and admin token. Security model
D
Daemon
The small program called mailroom that runs on your laptop. It connects out to the Hub, checks again the contract the Hub sends with each job (real paths, its own clock) and does the work. The laptop and the daemon
Daemon credential
The secret the laptop uses to connect. It starts with mrd_. You can rotate it from the Laptop page. The laptop and the daemon
Daily limit
The most parcels a key may send per UTC day, set in its contract. The Hub counts them. Keys and contracts
Desk
The mailroom word for the Hub: where parcels arrive and are checked. The big picture
Durable Object
A Cloudflare feature: one small program with its own storage, with one copy that handles requests one at a time. The Hub is one. How a parcel travels
E
Event
One line in the log: a number, a time, a kind and some details. It records that something happened. Events
Expiry
The moment a contract stops working. A date such as 2026-12-31 means the start of that day in UTC. It is optional. Keys and contracts
H
Hub
The part in the cloud that does the checking and keeps the records: keys, contracts, the parcel queue and the event log. It is one Cloudflare Worker and one Durable Object. How a parcel travels
K
Key
The secret an app shows with every parcel, so the Hub knows who is sending. See client key. Keys and contracts
L
Laptop
Where the work is really done: your own computer, running the daemon and Claude Code. The laptop and the daemon
M
MCP
Model Context Protocol. A standard way for an AI app, such as Claude, to call tools on another service. The Hub offers one at /mcp. Claude and other apps
O
Origin check
The Hub refuses a change that comes from a web page on another site. It stops other sites from using your signed-in browser. Security model
Owner
You. The one person who signs in to the web app and decides everything. The big picture
Owner session
The signed-in state of your browser: a cookie called mr_session that lasts 7 days. Security model
P
Parcel
One request that an app sends. The Hub calls it a job in the code and in the API. The Mailroom calls it a parcel everywhere else. Parcels and approvals
Plugin
A bundle for Claude Code. The Mailroom plugin connects it to the Hub and adds safety rules and two commands. Claude and other apps
Q
Queue
The line of parcels waiting for the laptop. They wait there while it is away and run in order when it returns. Parcels and approvals
R
Read (scope)
The base admin-token scope. It can look at everything but change nothing. Claude and other apps
Refused
A parcel that was turned away. The contract said no, the laptop's check said no, or you declined it. The reason is kept. Parcels and approvals
Revoke
Cut a key or token off for good. It stops working on its next use, and a revoked key's waiting, queued and running parcels are cancelled. Keys and contracts
Rotate
Replace a secret with a new one. Rotating the daemon credential kills the old one at once, so the laptop must be given the new one. The laptop and the daemon
S
Scope
One permission on an admin token: read, write or approve. Claude and other apps
Session
The period you are signed in. See owner session. Security model
Shown once
A secret appears on screen one time, when it is made. The Hub keeps only a hash, so it cannot show it again. Security model
State
Where a parcel is in its life: queued, waiting_approval, running, done, failed, refused or cancelled. HTTP API
Symlink
A file that points to another place. A symlink inside an allowed folder can point outside it, so the laptop looks at the real path before it acts. Security model
T
Task
The kind of work a parcel asks for: echo, read_file, write_file or claude. Parcels and approvals
Token
A secret string that proves who is calling. Here it usually means an admin token. Claude and other apps
W
Worker
A Cloudflare Worker is a small program that answers web requests. It is the front gate of the Hub and checks sign-in before anything else. How a parcel travels
Write (scope)
The admin-token scope that adds creating and revoking keys, and creating and editing contracts. Claude and other apps
